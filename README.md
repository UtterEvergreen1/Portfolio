# Daniel Losso-Kiss Portfolio Website

A responsive portfolio website showcasing my software development projects, with a focus on C++, game development, and Minecraft-related tools.

**Live Site:** [daniels.works](https://daniels.works)

## Brief Projects Overview

A mix of web apps and Minecraft tools:

- **Seedra** & **Seedra Engine** - a C++ API and a 3D renderer that recreate Minecraft Legacy Console Edition world generation and let you explore any world seed.
- **Legacy Converter** & **Legacy Minecraft Mapper** - a command-line tool and a desktop app for migrating and managing Legacy Console worlds.
- **Tascade** & **Steady Plan** - web apps that turn task management into something a bit more fun.
- **Peer Evaluation App** - a full-stack platform for students grading each other on group or solo work.

## Technology Stack

- **Bootstrap Studio** — visual design and layout tool
- **Bootstrap 5.3.6** — CSS framework
- **jQuery 3.7.0** — page interactions and AJAX
- **AOS 2.3.4** — scroll animations
